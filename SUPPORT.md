## 2. Collect Diagnostics Safely

Run `agent-token-receipt doctor` and check `--version`:

```bash
agent-token-receipt --version
agent-token-receipt doctor
```

## 3. Opening a GitHub Issue

If documentation does not resolve your question:
1. Open a **Bug Report** or **Feature Request** issue using the repository issue templates.
2. **Privacy Reminder:** Never include private prompts, repository source code, model thinking content, API keys, or raw session transcript files in any public issue.
